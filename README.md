# Star Wars Expert

A LangChain-powered application that provides expert knowledge about the Star Wars universe.

## Description

This project uses LangChain to create an intelligent assistant that can answer questions about Star Wars lore, characters, planets, and events.

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```python
# Example usage
python main.py
```

## Features

- Answer questions about Star Wars characters
- Provide information on planets and locations
- Explain events from the Star Wars timeline
- Interactive conversation interface

## Requirements

- Python 3.8+
- LangChain
- OpenAI API key (or other LLM provider)

## Configuration

Set your API key as an environment variable:

```bash
export OPENAI_API_KEY='your-api-key-here'
```
